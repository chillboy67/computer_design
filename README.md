# 元气罗盘 - 健康管理系统

计算机设计比赛参赛作品，基于 Python 开发的健康管理系统。

## 功能介绍

- 用户登录 / 注册
- 健康指标记录与跟踪
- AI 健康建议（基于 LLM）
- 运动处方管理
- SQLite 数据库存储

## 技术栈

- Python
- SQLite
- LLM API 集成

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```
